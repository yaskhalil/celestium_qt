# MISTAKES.md — Lessons Learned

## 2026-08-03 — System repair session (broken oracle/backtest path)

- **Config migrations leave stale refs.** The %-based risk limit migration (DLL_PCT, FLOOR_PCT…) removed `settings.DAILY_LOSS_LIMIT` / `BALANCE_FLOOR` / `SOFT_KILL_SWITCH` / `DAILY_PROFIT_CEILING` but backtest_engine, stress_test, and tests still referenced them → AttributeError at runtime, backtest.py dead on arrival. LESSON: after renaming/removing settings, grep the whole repo (src + scripts + tests) for the old names.
- **Tuple truthiness vetoed the firewall.** `if size > 0 and self.oracle.validate_trade(...)` — validate_trade returns a 2-tuple, always truthy → the backtest IGNORED every Oracle veto (DLL, GFV, position caps). The Oracle was fine; the caller swallowed the verdict. LESSON: unpack `(approved, reason)`; never bool-check a tuple.
- **Feature columns missing in the live path = theater gates.** DuckDBBuffer returned raw OHLCV; `add_regime_features` only ran inside classifier.predict on a transient copy. So map_to_bits read missing columns via .get(col, 0) → close>0 always true → "attractor" gate always passed; ATR defaulted to 1.0 → absurdly tight stops → stop-outs. LESSON: if a gate reads a feature, that feature must exist upstream; fail closed on missing columns (RegimeFilter now does).
- **Pydantic v2 silently drops unknown kwargs** (extra='ignore' default). Tests passed `daily_loss_limit=1100.0` to AccountState → dropped → assertions failed against wrong limits. LESSON: construct state via real fields only; assert on computed properties.
- **Time-dependent tests.** validate_trade's 16:55 cutoff uses wall clock; tests run at night hit it before the cap/ceiling checks. LESSON: always pass `current_time` explicitly in oracle tests.
- **Domain transplant (the "semi tensor" fluff).** The Boolean network / attractor / STP framing (from the cancer-cell modeling work) was pasted into the trading stack as boolean_network.py with magic numbers {1,3,7,9,11,15}. Same intent was a 3-line trend filter. LESSON: don't reuse exotic framing across domains; name things by what they actually do (RegimeFilter).
- **Test mocks vs real interfaces.** Tests mocked an old PositionManager interface (order_type/limit_price) and `MagicMock(spec=Oracle).validate_sell` returning an unpackable MagicMock. LESSON: after interface changes, rewrite tests against the current signature; set explicit return values on spec'd mocks.
- **Futures leftovers.** TICK_VALUE=2.0 multiplied backtest PnL on an ETF account; DailySession counted every fill against the trade cap (round trip = 2). LESSON: after broker migration (Rithmic → Alpaca), audit unit semantics everywhere.
- **NaN comparisons fail OPEN.** `if adx < threshold` is False for NaN — a degenerate zero-movement bar (all directional moves equal → ADX=0/0) slipped through the regime gate. LESSON: fail closed on both None AND NaN (`math.isnan`); add `_valid()` guard.
- **mcp 2.0 restructure.** `mcp` PyPI package v2 removed `mcp.server.fastmcp` (FastMCP). Code imports the v1 API — pin `uv add "mcp<2"` (1.29.0). LESSON: check the SDK's import path before upgrading major versions.
